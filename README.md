# COZY PETALS by Tanu
Boutique Showcase Website for Handcrafted Chenille Pipe-Cleaner Flowers & Gifts
Location: Khunti, Jharkhand, India
Instagram: [@cozypetalsbytanu](https://www.instagram.com/cozypetalsbytanu/)

---

## 🌸 Folder Structure
```
cozy-petals-website/
├── index.html        # Complete semantic HTML5 structure with SEO meta tags
├── style.css         # Custom responsive stylesheet (Warm Ivory & Plum palette)
├── script.js         # Mobile drawer, product filter, modal & WhatsApp automation
└── README.md         # Setup and customization guide
```

---

## 🚀 How to Run
1. Double-click `index.html` to open the website directly in any web browser (Chrome, Safari, Edge, Firefox).
2. No Node.js or local web server required.

---

## ⚙️ How to Update the WhatsApp Number
Open `script.js` in any code editor (Notepad, VS Code, etc.) and locate Line 7:
```javascript
const BRAND_WHATSAPP_NUMBER = '919876543210';
```
Replace `919876543210` with Tanu's actual WhatsApp phone number including the country code (e.g., `91` for India) without spaces or the `+` sign.
